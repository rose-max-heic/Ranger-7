# 🏕️ Ranger HQ

Personal study database untuk mahasiswa kedokteran — berisi rangkuman kuliah, panduan tutorial, dan latihan soal dalam format HTML interaktif yang bisa dibuka langsung di browser.

Dibuat oleh mahasiswi FK UMS, dipakai untuk belajar sendiri, dan dibagikan kalau ada yang mau ikut pakai.

---

---

## 🚀 Cara Pakai

Tidak perlu install apapun. Cukup:

1. Clone atau download repositori ini
2. Buka file `index.html` di browser
3. Navigasi ke blok yang diinginkan

Atau kalau sudah di-deploy, buka link-nya langsung.
